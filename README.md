# **📌 Descrição do Projeto - Login Page**  
Este projeto consiste em uma Página de login, utilizando **Angular** e **TypeScript**. O objetivo é praticar o uso do framework e as respectivas linguagens utilizadas. 

# **Obs:**
As folhas caindo no background foram feitas com apenas duas imagens e animadas utilizando css

- Angular  
- HTML  
- CSS   
- TypeScript  

## 🚀 **Como executar o projeto**  
1. Clone o repositório 
2. Execute npm install no terminal do projeto
3. Execute ng s no terminal
